# **[Gypsy Swing Revue](https://gypsyswingrevue.com)**

## Development

To start:

```bash
pipenv shell
py manage.py runserver
```

In a seperate terminal run vite to compile assets (scss, js).

```bash
npm run dev
```

Use py scripts/generate_images.py to generate images. (Overwrites)
